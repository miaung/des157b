Usability Results

Three significant observations

  • Scrolling: The user spent a lot of time scrolling through each sentence. I believe that this could be improved by reducing the delay between each scroll.
  • Slider Confusion: Due to the slider still being a work in progress, the user was confused on what the intention of the slider is. I will need to update the slider with the full functionality and retest.
  • Navigation: The user automatically started scrolling without being prompted to. However, I think it will be beneficial to add an arrow to guide the user.

Overall thoughts

I need to reduce the delay between each sentence so that the user won't have to scroll as m uch. I also need to finish the slider function. Users were able to navigate without guidance, but I believe adding an arrow will be helpful. Overall, the user felt that the project was ominous, which was my intention so that was successful. TO make the project stronger, I'll have to finish the slider function and test that with users.
